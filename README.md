# bst-digital-test-task
Ссылка на задачу: https://github.com/Hexlet/ru-test-assignments/tree/main/data-scientist/bst-digital

Задача: Найти оптимальный набор букв на складе для максимизации прибыли.
Условия:

Цена проданного слова: +40 руб.

Штраф за неудачу (не хватает 2+ букв): -10 руб.

Экспресс-доставка 1 буквы: -2 руб. (итоговая прибыль +38 руб.)

Хранение 1 буквы: -1 руб./день

Склад сбрасывается каждый день (буквы не переносятся).

Регистр не важен, пунктуация игнорируется.

Алгоритм:

Очистка данных: Извлекаем слова из четверостишья, убираем знаки препинания, приводим к нижнему регистру.

Подсчет: Для каждого слова считаем частотность букв (collections.Counter). Находим максимальное количество каждой буквы среди всех слов (больше хранить не имеет смысла).

Функция прибыли (evaluate_stock): Для заданного склада (словаря буква: количество) считаем прибыль по каждому слову. Если не хватает 0 букв — +40, если 1 — +38, если 2 и более — -10. Из общей суммы вычитаем стоимость хранения всех букв.

Оптимизация: Так как функция нелинейная (из-за штрафов и порогов), используем локальный поиск (Hill Climbing с рестартами). Алгоритм случайно инициализирует склад, а затем пошагово добавляет или убирает буквы, если это увеличивает общую прибыль.
